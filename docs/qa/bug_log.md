# UniBite GP1 Bug Log (`docs/qa/bug_log.md`)

| Bug ID | Summary & Reproduction Steps | Severity | Status | Fix Verification |
|---|---|---|---|---|
| **BUG-001** | **Overlay exception & 99,399px RenderFlex overflow on startup:** Placing `DemoControlBar` (which used `PopupMenuButton` with a `Tooltip`) inside `MaterialApp.router(builder: ...)` placed it outside `GoRouter`'s `Navigator`/`Overlay` ancestor. | **Critical** | **Fixed & Closed** | Moved shell chrome inside `GoRouter`'s `ShellRoute` (`_AppShellChrome`), then later removed the top `DemoControlBar` banner per user request. Verified with `app_shell_smoke_test.dart`. |
| **BUG-002** | **`AppLocalizations.mealCategoryLabel` getter shadowed extension method:** `app_en.arb` defined `"mealCategoryLabel": "Category"`, causing analyzer `invocation_of_non_function_expression` errors when calling `l10n.mealCategoryLabel(cat)`. | **Major** | **Fixed & Closed** | Renamed helper in `l10n_extensions.dart` to `localizedMealCategory(cat)` and updated all call sites. Verified with `dart analyze` (`No issues found!`). |
| **BUG-003** | **Truncated `IBMPlexSansArabic-Medium.ttf` download (`10,000` bytes):** Initial curl download aborted mid-stream. | **Major** | **Fixed & Closed** | Re-downloaded full `224,816` byte `IBMPlexSansArabic-Medium.ttf` and verified all 6 `.ttf` font files load cleanly in Flutter widget/golden tests. |
| **BUG-004** | **Hard-coded `Color(0x...)` literals in legacy widgets (`state_views.dart`, `offline_banner.dart`, dashboards):** Legacy theme used inline color hexes instead of strict `UniBiteColors` tokens. | **Minor** | **Fixed & Closed** | Audited and migrated all screens/widgets to `UniBiteColors` + `UniBiteTokens` + `LucideIcons`; automated token grep confirmed zero un-tokenized colors outside `colors.dart`. |
| **BUG-005** | **2.0 px bottom RenderFlex overflow in `CafeteriaMenuScreen` filter header:** Fixed-height `SliverPersistentHeader` (`122 px`) clipped by 2 px on compact `360x640` mobile viewports and larger text scales. | **Major** | **Fixed & Closed** | Replaced `_StickyMenuFilterHeader` with an intrinsic `SliverToBoxAdapter` wrapping `Column(mainAxisSize: MainAxisSize.min)` and verified cleanly on `360x640` viewport. |
| **BUG-006** | **Black background + skeleton shimmer stuck on Logout:** Dashboard/Student shells returned a bare `LoadingView()` without a `Scaffold` when `currentUserProvider` became `null`, while `app_router` could read a stale cached `currentUserProvider` before redirect completed. | **Critical** | **Fixed & Closed** | Read authoritative `localStorageServiceProvider.getSessionUser()` in `GoRouter.redirect`, added explicit `context.go('/login')` after `logout()`, wrapped null-user loading placeholders in `Scaffold`, and verified end-to-end logout in `app_shell_smoke_test.dart`. |
| **BUG-007** | **Duplicate `<default FloatingActionButton tag>` Hero error on dashboards:** Multiple `FloatingActionButton.extended` widgets inside `IndexedStack` tabs in `CafeteriaAdminDashboardScreen` and `SystemAdminDashboardScreen` shared the default FAB hero tag during route transitions. | **Critical** | **Fixed & Closed** | Set `heroTag: null` on every FAB across both dashboards so `IndexedStack` tabs never attach duplicate Hero widgets. |
| **BUG-008** | **46–48 px horizontal RenderFlex overflow in `UbSecondaryButton` (`components.dart:156`):** Side-by-side `UbSecondaryButton` widgets in `Expanded` columns (e.g., Opening/Closing time pickers) overflowed horizontally on compact mobile viewports. | **Major** | **Fixed & Closed** | Wrapped `UbSecondaryButton`'s `Text` label inside `Flexible` with `maxLines: 1` and `TextOverflow.ellipsis`. |
